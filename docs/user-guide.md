# Руководство пользователя Personal OS

## 1. Быстрое добавление (Quick Add)
- Нажмите `Cmd + K` (macOS) или `Ctrl + K` (Windows/Linux) в любом месте приложения.
- Введите задачу, расход или событие на естественном языке:
  - `Оплатить сервер 1500 руб завтра в 14:00 !high #finance`
- AI-парсер мгновенно извлечет дату, приоритет, категорию и сумму.

## 2. Канбан-доска задач
- Переключайтесь между видами **Список** и **Доска** в разделе `/tasks`.
- Перетаскивайте карточки между колонками для смены статуса.
- Случайное выполнение можно мгновенно отменить кликом на кнопку **Отменить** во всплывающем Toast-уведомлении.

## 3. Telegram-бот
- Подключите Telegram в настройках `/settings/integrations`.
- Отправляйте боту текстовые или голосовые сообщения:
  - *"Купил обед за 450 рублей"* -> бот зафиксирует расход в категории Еда.
  - *"Напомни позвонить врачу в пятницу в 11:00"* -> бот создаст задачу.
